# Security policy

## Security maintainer

André Maree (GitHub [@ammaree](https://github.com/ammaree)), KSS Technologies (Pty) Ltd., is the security maintainer for the open-source components in the [ksstech](https://github.com/ksstech) organization.

Report a vulnerability to andrem@kss.co.za. Include the repository, the version or commit, and a way to reproduce the issue. Do not file a public GitHub issue for a suspected vulnerability.

## Scope

This policy covers the public repositories published by KSS Technologies under ksstech, including the embedded libraries and device firmware in this organization.

## Response

The security maintainer acknowledges the report and coordinates the fix in the affected repository.
